# Energy Research Lab

Repository per ricerca e analisi dei sistemi energetici.

## Fonti dati

- Terna
- ARERA
- GSE
- GME
- ISTAT
- Eurostat

## Workflow

1. Acquisizione dati
2. Pulizia dati
3. Analisi
4. Modellazione
5. Visualizzazione
6. Reportistica

## Struttura

data/raw       -> dati originali
data/processed -> dati elaborati
projects       -> progetti di ricerca
outputs        -> risultati
models         -> modelli
